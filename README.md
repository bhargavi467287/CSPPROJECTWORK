# Bambookart 🎋
## Empowering Bamboo Artisans Through Sustainable Products and Digital Promotion
### Community Service Project (CSP) E-Commerce Platform

---

## 📌 Project Overview
**Bambookart** is a clean, modern, responsive e-commerce web platform developed as an academic **Community Service Project (CSP)**. The core objective is to revive and digitally promote the traditional handmade bamboo craft heritage of rural artisan communities (specifically the **Medara** artisan community in Andhra Pradesh and Telangana) by connecting them directly with conscious modern consumers.

### Key Objectives:
1. **Direct Artisan Livelihood:** Eliminate exploitative market intermediaries and middlemen so artisans receive fair wages directly.
2. **Eco-Friendly Living:** Provide natural, 100% biodegradable bamboo alternatives to hazardous single-use and domestic plastics.
3. **Heritage Preservation:** Preserve indigenous weaving crafts such as *Chattalu* (winnowing baskets), *Jalledalu* (flour sieves), and *Gampalu* (harvest baskets).
4. **Digital Inclusion:** Bridge the digital divide by offering a simple, bilingual (English & Telugu) e-commerce marketplace.

## ✨ Implemented Features (100% Functional)

1. **Homepage:**
   - Top announcement strip with delivery threshold and CSP tag.
   - Sticky navigation header with search, user account, wishlist counter, and cart badge.
   - High-impact hero banner with natural bamboo background, dual CTAs, and live product preview.
   - Trust & impact bar highlighting direct artisan support and zero plastic guarantee.
   - Category showcase cards with smooth filtering.
   - Featured products grid with price filters and sorting options.
2. **Product Listing & Categories:**
   - Filter by categories: Baskets, Vegetable & Fruit, Storage, Trays, Sieves, Winnowing Chattalu, Sticks & Crafts.
   - Filter by price ranges: All, Under ₹200, ₹200–₹400, Above ₹400.
   - Sort by: Featured, Price: Low to High, Price: High to Low, Customer Rating.
3. **Instant Search:**
   - Interactive live search with instant auto-suggestion dropdown.
   - Searches across product names, descriptions, Telugu names, and artisan names.
4. **Product Details Modal & View:**
   - High-resolution SVG visual representation.
   - Artisan profile card (who made the craft, their village, and days required to weave).
   - Technical specifications table (dimensions, material, handcrafting time, origin).
   - Quantity selector (+ / -) with Add to Cart and Buy Now buttons.
5. **Cart System (Drawer + Dedicated Page):**
   - Slide-over cart drawer from any page.
   - Real-time item subtotal, free shipping progress bar, and eco packaging guarantee.
   - Quantity updater and item removal.
   - Persistent across browser sessions via `localStorage`.
6. **Wishlist:**
   - Heart toggle on every product card.
   - Dedicated Wishlist view with quick "Move to Cart" action.
7. **Demo User Authentication:**
   - Modal login/register system.
   - **⚡ Quick Fill Demo User** button for single-click testing.
   - User profile indicator in header with logout capability.
8. **Checkout Flow:**
   - Step 1: Customer details & delivery address form.
   - **⚡ Auto-Fill Sample AP/Telangana Address** button for quick demonstration.
   - Step 2: Payment method selection:
     - Cash on Delivery (COD).
     - Demo Online Payment with instant simulation (Google Pay / PhonePe / Cards).
   - Step 3: Real-time order summary calculation.
9. **Order Confirmation & Printable Invoice:**
   - Unique Order ID generation (e.g., `BK-2026-XXXX`).
   - Detailed order invoice with customer address, artisan credit, and itemized receipt.
   - Working **🖨️ Download / Print Invoice** button using native browser print.
10. **My Orders Page:**
    - Displays all placed orders saved in `localStorage`.
    - Real-time status badge ("Order Placed", "In Handcrafting", "Shipped").
    - One-click "Order Again" button to reorder past items.
11. **Our Artisans Page:**
    - Detailed artisan profiles with photos, craft specialty, village/district, and generational quotes:
      - *Medara Ramaiah* (East Godavari)
      - *P. Lakshmi Devi* (Chittoor)
      - *K. Subba Rao* (Warangal)
      - *Ch. Saradamma* (Srikakulam)
    - 4-step traditional crafting journey (Eco-Harvesting -> Sun Curing -> Hand Splitting -> Master Hand Weaving).
12. **About Us Page:**
    - In-depth explanation of the Community Service Project (CSP) title, objectives, problem statement, mission, and core pillars.
13. **Contact Us Page:**
    - Interactive inquiry form with feedback.
    - CSP academic coordinator, faculty guide, and artisan helpline information.
    - Expandable FAQ accordion addressing common consumer questions.
14. **Dual Language Switcher (English & Telugu - తెలుగు):**
    - Instant one-click toggle in the top bar.
    - Completely translates navigation, product titles, categories, buttons, artisan bios, checkout forms, and receipts into Telugu.

## 🚀 How to Run Locally on Windows

You can run Bambookart locally using any of the three methods below:

### Method 1: Using Node.js (Recommended)
Open PowerShell or Command Prompt in the `c:\csp` directory and run:
```powershell
node server.js
```
Then open your web browser and navigate to:
```
http://localhost:8000
```

### Method 2: Using Python
If you prefer Python:
```powershell
python -m http.server 8000
```
Then open your web browser and navigate to:
```
http://localhost:8000
```

### Method 3: Direct Browser Launch (No server required)
You can directly open `index.html` in Chrome, Edge, or Firefox:
```powershell
start index.html
```
